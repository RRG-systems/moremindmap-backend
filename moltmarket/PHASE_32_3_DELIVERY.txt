================================================================================
WHAT WAS FIXED (7 MAJOR PROBLEMS → 7 SOLUTIONS)
================================================================================

PROBLEM 1: Duplicate Parent State
  - Before: parent_strategy in dashboard_state AND evolution_engine (out of sync)
  - After: evolution_engine.current_parent is single authoritative source
  - Both dashboard_state and evolution_engine read/write from same object

PROBLEM 2: Promotion Didn't Update Evolution Engine
  - Before: promotion endpoint only updated dashboard_state['parent_strategy']
  - After: promotion calls evolution_engine.promote_baby_to_parent()
  - Result: next spawn correctly inherits promoted baby's config

PROBLEM 3: Spawn Read From Stale Parent
  - Before: spawn_baby_variants() could use outdated parent_strategy
  - After: always reads from evolution_engine.current_parent (authoritative)
  - Result: Gen 2 babies inherit from promoted parent, not baseline

PROBLEM 4: No Lineage Encoding in Names
  - Before: baby_001, baby_002 (no parent indicator)
  - After: baseline-01, baseline05-01, baseline0501-01 (parent-encoded)
  - Result: Users see lineage at a glance

PROBLEM 5: CSV Parent_id Incorrect After Promotion
  - Before: parent_id always baseline (even for Gen 2)
  - After: parent_id shows true parent (baseline for Gen 1, promoted ID for Gen 2)
  - Also added: parent_generation field

PROBLEM 6: Arena DNA Transfer Unverified
  - Before: No explicit transfer of promoted baby's config to arena
  - After: promote_baby_to_parent() updates current_parent with full DNA
  - Result: Arena uses promoted baby's parameters (entry_threshold, stop_loss, etc.)

PROBLEM 7: Generation Tracking Broken
  - Before: all babies Gen 1 regardless of parent generation
  - After: child generation = parent generation + 1
  - Result: Gen 1 → Gen 2 → Gen 3 tracking works correctly
