### Key Findings
1. **Paper vs Shadow Divergence Audit**: Paper trading system is fundamentally broken
   - Paper compares entry_bid to future_price SNAPSHOTS (arbitrary)
   - Shadow records actual execution fills and P&L (ground truth)
   - Paper outcomes are THEORETICAL, not actual trading results
   - Win rate difference: 45% paper vs 43% shadow (misleading)
   - **Verdict: Paper system should be DISABLED**

2. **Protection Layer Deployment (Apr 9 21:24 UTC)**
   - Toxic fill detection: Working (7.4% of losses are immediate adverse moves)
   - Market failure blocklist: Working (blocks after 3+ losses in 48h)
   - **Bug found and FIXED**: Blocklist not enforced before shadow_execute()
   - Added double-check enforcement + detailed rejection logging

3. **Phase 2 vs Phase 3 Analysis (Last 80 hours)**
   - Phase 2 (7.2h): 6 shadow closed, 33% win rate, -$0.16 P&L
   - Phase 3 (72.8h): 48 shadow closed, 44% win rate, -$3.03 P&L
   - Win rate improved +10.4% but P&L worsened 2.3x per trade
   - Paper-shadow divergence narrowed 80% (16.7% → 3.3%)
   - **Failure modes**: 52% timing lag, 41% liquidity traps, 7% toxic fills

4. **System Health**
   - Still unprofitable (-$0.063 avg P&L per shadow trade)
   - Protection layer is defensive (catching bad exits) but not offensive (improving entries)
   - Main problem: Entry signal quality + exit timing
   - Blocking ~48% of trades prevented more losses but didn't improve profitability

## MOREMINDMAP — TAILWIND CSS FIX & API DEPLOYMENT (Apr 13 13:00-14:41 MST)

### Tailwind Pipeline Root Cause (RESOLVED)
- **Issue**: `.bg-black`, `.text-white`, `.border-white/10` etc. missing from compiled CSS
- **Root cause**: `@tailwindcss/vite` v4 was NOT scanning JSX source files properly
  - Only found classes in MiniProfileReport component CSS files
  - App.jsx, Profile.jsx, RealEstate.jsx classes never extracted
  - Build: 16 kB CSS but missing all App utility classes

- **Fix applied**:
  1. Removed `@tailwindcss/vite` from dependencies
  2. Installed traditional `tailwindcss` + `postcss` + `autoprefixer`
  3. Created `postcss.config.cjs` with proper PostCSS pipeline
  4. Updated `vite.config.js` (removed Tailwind plugin)
  5. Verified content paths in `tailwind.config.js`

- **Result**: CSS bundle grew to 24.13 kB with ALL utilities present
  - `.bg-black` ✓ now present with full rule
  - `.text-white` ✓ now present
  - `.border-white/10` ✓ now present
  - All animation/shadow/layout classes ✓
  - Commit: `ca83a04` (Move @tailwindcss/vite to devDependencies only)
  - Commit: `090ae1c` (Fix Tailwind pipeline: move @tailwindcss/vite to devDependencies)

### Production API Routing Issue (CRITICAL - RESOLVED)
- **Problem**: Frontend deploy worked, but `/profile` route showed "Failed to fetch"
- **Root cause**: Frontend calling `http://localhost:4242/api/moremindmap-mini-profile`
  - VITE_API_URL env var not being injected by Vercel build
  - Localhost fallback was being used in production

- **Diagnostic**: 
  - Fetched live CSS asset hash from Vercel deployment (index-DWIoT4vc.css)
  - Checked compiled CSS for required selectors → FOUND ALL (so CSS was correct)
  - Fetched live JS bundle → found hardcoded `http://localhost:4242` calls
  - Confirmed old build was serving old API URLs

- **Initial fix attempt**: Changed Profile.jsx and RealEstate.jsx to detect production:
  ```javascript
  const API = import.meta.env.VITE_API_URL || (import.meta.env.PROD ? "https://moremindmap-api.vercel.app" : "http://localhost:4242")
  ```

### API Architecture Redesign (FINAL SOLUTION)
- **Discovery**: Vercel doesn't route `/api/*` to serverless functions when using Vite as the framework
  - Static Vite builds to `dist/` and serves only frontend files
  - Created `/api` serverless handlers but they were never invoked (404 errors)

- **Solution**: Separate backend and frontend into two Vercel projects
  1. **Frontend**: https://moremindmap.com (Vite static site + Vercel)
  2. **Backend**: https://moremindmap-backend.vercel.app (Express + Vercel)

- **Files changed**:
  - `src/Profile.jsx`: Changed API URL to `https://moremindmap-backend.vercel.app`
  - `src/RealEstate.jsx`: Changed API URL to `https://moremindmap-backend.vercel.app`
  - `vercel.json` (frontend): Simplified (removed API functions config)
  - Deleted `/api` folder from frontend (moved to backend project)

- **Backend project created** (`~/moremindmap-backend/`):
  - `server.js` (copied from moremindmap)
  - `engine/` folder (scoring + profile generation)
  - `package.json` with Express, Stripe, OpenAI dependencies
  - `vercel.json` with Node.js runtime config for Vercel deployment
  - `.gitignore` for Node.js

- **Commits**:
  - `63cb8e3` (frontend): Remove frontend /api handlers (using separate backend service)
