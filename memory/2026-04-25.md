### 3. BRAIN Calibration Engine (COMPLETE)
- **File:** `brain_calibration_engine.py` (6.6KB)
- **Three modes:**
  - **AGGRESSIVE:** Position 1.5x, entry 0.01, exit 0.005, 15 concurrent → high conviction
  - **MODERATE:** Position 1.0x, entry 0.03, exit 0.015, 8 concurrent → balanced
  - **CONSERVATIVE:** Position 0.5x, entry 0.05, exit 0.03, 3 concurrent → low risk

- **Endpoints:**
  - `POST /api/brain/calibrate` — Apply style (Conservative/Moderate/Aggressive)
  - `GET /api/brain/calibrations` — List all modes
  - `POST /api/brain/recommend` — Auto-recommend based on baby stats (win rate + sign flips)

- **Integration:**
  - Calibration saved to `brain_config.json`
  - Applied instantly when baby promotes
  - All new babies spawn with tuned parameters

- **Testing:**
  - Tested all 3 modes: all returned correct configs
  - Tested auto-recommendation: 58% win rate → AGGRESSIVE ✅
  - Tested persistence: config saved and readable

## Key Decisions

1. **File-based message queue** — No database. JSONL in `/tmp`. Simple, portable, debuggable.
2. **Polling from frontend** — 500ms refresh. Fast enough for trading, simple to maintain.
3. **Random personality** — 40+ messages keeps it fresh. Each session feels different.
4. **Calibration on demand** — Apply whenever you want, affects next generation of babies.
5. **Endpoints are idempotent** — Can calibrate multiple times, always latest wins.
