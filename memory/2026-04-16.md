# 2026-04-16 - MOLTmarket Run Isolation Fix

## Issue Reported (22:50 MST)
**Partial run-isolation failure** - Only 4 metrics NOT resetting after "New Run":
- `total_trades` (showing old value instead of 0)
- `rolling_win_rate` (showing old value instead of 0)
- `avg_entry_slippage` (showing old value instead of 0)
- `trade_sign_flips` (showing old value instead of 0)

All other metrics reset correctly.

## Root Cause Analysis
Found the bug in `dashboard_data_layer.py`:

**`get_trades_by_source(source)` function was NOT filtering by `current_run_id`**

```python
# BUGGY CODE:
def get_trades_by_source(self, source):
    return [t for t in self.trades if t.get('source') == source and t.get('asset') != 'RUN_SEPARATOR']
    # ^ This returned ALL trades across ALL runs!
```

This broke 2 dependent functions:
1. `get_trade_integrity()` - calls `get_trades_by_source('paper')` and `get_trades_by_source('shadow')`
2. `get_avg_slippage()` - calls `get_recent_trades()` (already fixed, but needed verification)

## Fixes Applied (22:50-22:56 MST)

### Fix 1: `get_trades_by_source()` - CRITICAL FIX
Changed from global to run-filtered:
```python
def get_trades_by_source(self, source):
    """PHASE 32.5G: Get trades from specific source - FILTERED BY CURRENT RUN"""
    if self.current_run_id:
        return [
            t for t in self.trades 
            if t.get('source') == source and t.get('asset') != 'RUN_SEPARATOR' 
            and t.get('run_id') == self.current_run_id  # ← KEY FIX
        ]
    else:
        return [t for t in self.trades if t.get('source') == source and t.get('asset') != 'RUN_SEPARATOR']
```

### Fix 2: Added explicit trace logging to all 4 metrics
- `get_avg_slippage()` now logs: `run_id`, `trades_count`, `entry_bps`, `exit_bps`
- `get_trade_integrity()` now logs: `run_id`, `paper_trades`, `shadow_trades`, `sign_flip_rate`
- `update_metrics()` now logs each metric calculation step-by-step
