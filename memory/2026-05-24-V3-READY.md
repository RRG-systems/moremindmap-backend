## Lessons Learned

### On V3 Rendering
- Sectional voices work: Each section reads differently
- Anti-repetition memory essential: Without it, AI cadence dominates
- Local fallback is non-negotiable: Guarantees content always renders
- Cache version control critical: Schema changes need auto-invalidation

### On Blockers
- Stale cache worse than no cache: Old data hidden in localStorage
- Wrapped objects break React: Always unwrap data before passing to components
- Diagnostic logging essential: Production failures need context

### On Scale
- 7 sections is optimal: Enough for depth, not too many for complexity
- 3-6 minute generation acceptable: Longer than users prefer, but tolerable
- Profile ID enables monetization: Future recovery/sharing product
