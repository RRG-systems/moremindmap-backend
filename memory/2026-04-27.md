## RRG WAVE ANIMATION — CURRENT IMPLEMENTATION (12:26 MST)

### What's Working Now
**4-layer SVG wave system with:**
- Positions: 5%, 12%, 19%, 26% (high on page, near top)
- Wave heights: Small amplitude (Q control points 3-6px)
- Brightness: Ranges 0.21→0.42 opacity (bright, soft pulsing)
- Animation: Horizontal scroll (32s, 40s, 36s, 44s cycles)
- Modulation: Synchronized opacity + stroke-width pulsing (8s-10s cycles, ease-in-out)

### SVG Path Structure
Each wave uses quadratic Bezier curves:
```
d="M0,30 Q75,4 150,30 T300,30 T450,30 T600,30 T750,30 T900,30 T1050,30 T1200,30"
```
- Viewbox: `0 0 1200 60`
- M: Move to start (0,30)
- Q: Quadratic curve to control point (75, amplitude) then endpoint (150, 30)
- T: Smooth quadratic to continue wave

### Gradients (all 4 waves similar)
```xml
<linearGradient id="gradX" x1="0%" y1="0%" x2="100%" y2="0%">
  <stop offset="0%" style="stop-color:rgba(255,255,255,0);stop-opacity:1" />
  <stop offset="25%" style="stop-color:rgba(255,255,255,0.45);stop-opacity:1" />
  <stop offset="50%" style="stop-color:rgba(255,255,255,1);stop-opacity:1" />
  <stop offset="75%" style="stop-color:rgba(255,255,255,0.45);stop-opacity:1" />
  <stop offset="100%" style="stop-color:rgba(255,255,255,0);stop-opacity:1" />
</linearGradient>
```
- Peak brightness at 50% (center of wave)
- Fades to transparent at edges
