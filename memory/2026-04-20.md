# 2026-04-20 - MOLT Feed Population Problem

## Problem Statement
MOLT feed returns empty: `{"count":0,"posts":[],"status":"success"}`

Agents are set up to **react** to posts, but nothing creates **initial observations** of simulation outcomes.

## Root Cause
**Missing Observation Layer**: The simulation loop runs but never calls:
- `molt.log_agent_note()` 
- `molt.log_agent_proposal()`
- `molt.observe_trade_execution()`

So the MOLT database has zero posts, and the reaction loop has nothing to react to.

## Solution Built
Created `/Users/rrg/.openclaw/workspace/molt/agent_observation_layer.py`

This new layer:
- Observes trade completions (paper vs shadow divergence)
- Posts when win/loss streaks form (3+ in a row)
- Posts when drawdown spikes
- Posts when mutation hypotheses spawn
- Posts when babies get promoted/eliminated

Each observation triggers agents to post to MOLT feed via `molt.log_agent_note()`.

## MOLT ARCHITECTURE (Architect-Approved 2026-04-20 22:36)

### The Vision: Global Evolutionary Idea Market

**Local arena (yours):**
- Your 3 agents (Overfitter, Explorer, Risk Manager) spawn babies autonomously
- They evolve locally, find winners
- You can promote winners to main strategy

**Global MOLT (future):**
- OpenClaw agents worldwide post ideas, mutations, results
- Real-world reporting: sandbox wins vs. live deployment wins
- Agent-weighted consensus (NOT human votes)
- You import strong candidates into local testing

**Critical gates (architect requirement):**
- NOT community votes (kills system with noise)
- NOT direct arena promotion (skips validation)
- YES agent consensus + hard metrics gates

### The Disciplined Flow

```
MOLT Feed (ideas posted)
    ↓
Local Test Queue (selected for testing)
    ↓
Nursery (1 canonical + 10 variants run live)
    ↓
Agent reactions + metrics evaluation
    ↓
Promotion Button (if metrics pass + agent consensus)
    ↓
Arena (winners go live with real capital)
```

### What Gets Promoted

**NOT on likes alone.** Promotion requires:
- ✅ Survival gates (max drawdown <5%, no sudden collapse)
- ✅ Sample size (50+ trades minimum)
- ✅ Trajectory (win rate 40-60% range, stable)
- ✅ Hypothesis health (execution costs factored in)
- ✅ Agent consensus (at least 2/3 agents endorse)

**Likes = signal only.** Metrics = gate.

### Key Features to Build

**Phase 1 (Next):**
1. **Agent proposal layer** — Agents autonomously propose hypotheses and spawn babies
2. **Like button in MOLT** — Agents can endorse/oppose ideas
3. **Real-world reporting** — Posts tagged: sandbox | live-sim | real-deployment
4. **Genealogy tracking** — Local vs. imported lineage visible

**Phase 2 (Later):**
1. **Local Test Queue UI** — Visual staging area showing ideas queued for nursery
2. **Consensus voting** — Agents vote; lights up "Worth Testing" or "Promote to Arena"
3. **Global MOLT integration** — Outside agents post; you see their results
4. **Import flow** — Pull global winners into local test queue

**Phase 3 (Future):**
1. **Decentralized sharing** — Your winners post back to global MOLT
2. **Cross-arena genealogy** — Track ideas flowing between arenas
3. **Reputation scoring** — Agents build credibility across global network

### Why This Works

- **Local speed:** Your 3 agents iterate fast, find quick wins
- **Global reach:** You benefit from 100s/1000s of other agents' research
- **Validation:** No idea goes live without local testing + agent consensus + metrics
- **Discipline:** Separates signal (likes) from gates (metrics)
- **Modularity:** MOLT ≠ Nursery ≠ Arena (clean separation of concerns)

### What NOT to Build

❌ Auto-promotion based on votes alone
❌ Direct MOLT → Arena promotion (skip local testing)
❌ Second hidden testing engine (use Nursery as proving ground)
❌ Community upvotes/Reddit-style karma
❌ Global winners straight into live capital
