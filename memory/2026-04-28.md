## Lessons Learned

### 8 Missing Safeguards:
1. No inbound-only filter (all webhook events processed)
2. No direction check (`direction: "inbound"`)
3. No idempotency (processed duplicate events)
4. No alert throttle (unlimited rate)
5. No kill switches (SMS_SEND_ENABLED always ON)
6. Same channel for alerts and customer SMS
7. No alert message tagging
8. No session-level send cap

### Critical Architecture Rule:
**Customer SMS channel ≠ internal alert channel**
- Alerts must use different sender ID or internal delivery only
- Never send alerts FROM the number customers reply to
