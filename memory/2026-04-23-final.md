## What's Broken

**Leaderboard API shows zeros despite correct ledger data:**
```json
{
  "trades": 0,
  "shadow_pnl": 0.0
}
```

**But ledger has:**
```
total_trades: 1
shadow_pnl: 15.566063
```

## Why

Leaderboard endpoint reads from baby object in memory. That object gets updated during execution, but the JSON serialization doesn't see those updates.

## Fix

Make leaderboard read directly from `unified_ledger.get_trader_metrics()` instead of baby object fields.

**File:** moltmarket_dashboard.py
**Function:** /api/nursery/leaderboard
**Change:** 3 lines

```python
# OLD
trades_count = baby.get('total_trades', 0)

# NEW
if unified_ledger:
    metrics = unified_ledger.get_trader_metrics(variant_id)
    trades_count = metrics.get('total_trades', 0)
```
