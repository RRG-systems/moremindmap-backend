### Promotion Flow Verified
1. User clicks promote button on positive-PnL baby
2. Frontend POST to `/api/nursery/promote/{variant_id}`
3. Backend validates: shadow_pnl > 0 ✅
4. Backend loads baby DNA into dashboard_state['parent_strategy_dna'] ✅
5. Backend calls simulator.set_promoted_parent_dna(dna) ✅
6. Backend sets trading_enabled=True, brain_state=PROBATION ✅
7. Arena begins trading (at 1% size via PROBATION mode)
8. **Missing link:** Arena's `/api/arena/dna` endpoint should return promoted baby's DNA, but returns baseline

### Design Decision
- Nursery babies are independent traders (ignore BRAIN state)
- Arena respects BRAIN state (FLAT blocks, PROBATION throttles, ACTIVE trades freely)
- Promotion = swap Arena's DNA, unlock trading, trigger Nursery respawn
- THINK panel explains mode and guides user through promotion flow
